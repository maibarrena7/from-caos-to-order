Encuentro 6 · Integración y revisión del proyecto

Semana 3 · Control de versiones e integración

NotaDiapositivas

Abrir las diapositivas del encuentro (en pantalla completa con la tecla F).

Al terminar este encuentro vas a poder

  1. Evaluar la organización y reproducibilidad de un proyecto con una checklist.
  2. Dar y recibir devoluciones sobre un proyecto.
  3. Identificar los próximos pasos para compartir datos y código.
  4. Planificar una práctica concreta para un proyecto propio.

Actividad 1: revisión cruzada

En parejas, 30 minutos.

  1. Intercambiá tu proyecto con otra persona (por GitHub, pendrive o zip).
  2. Tratá de correr su análisis usando solo el README, sin preguntarle nada.
  3. Recorré la checklist.
  4. Dejale dos comentarios: una cosa que funciona y una que mejorarías.

Actividad 2: comparar con la referencia

Descargá el proyecto de referencia y comparalo con el tuyo. ¿Tomaste decisiones distintas? ¿Por qué?
