Antes del taller

Guía de instalación · unos 30–45 minutos

Para aprovechar los encuentros necesitás tener cuatro cosas instaladas y funcionando en la computadora que vas a traer. Hacelo con tiempo, y con buena conexión a internet: algunas descargas son pesadas.

Qué es Para qué lo usamos
1. R El lenguaje Correr los análisis
2. RStudio El programa donde escribimos y corremos R Todo el taller
3. Paquetes de R (tidyverse y here) Herramientas extra para R Leer Excel, ordenar datos, hacer figuras
4. GitHub Desktop + cuenta de GitHub Control de versiones Encuentro 5
Tip¿Ya tenés R y RStudio?

Saltá directo al paso 3 y corré el script de prueba. Si te dice que tu versión de R es vieja, volvé al paso 1.

Advertencia¿Computadora de la facultad o del trabajo?

Muchas veces no dejan instalar programas sin permiso de administrador. Si es tu caso, avisame antes del taller y lo resolvemos.

Paso 1: instalar R

R tiene que instalarse antes que RStudio.

  • Windows
  • macOS
  • Linux
  1. Entrá a https://cran.r-project.org.
  2. Hacé clic en Download R for Windows y después en base.
  3. Hacé clic en Download R-x.x.x for Windows (el número es la versión más nueva).
  4. Abrí el archivo descargado (R-x.x.x-win.exe).
  5. Si Windows pregunta si permitís que la aplicación haga cambios, decí Sí.
  6. Elegí el idioma y dejá todas las opciones como vienen: Siguiente hasta el final y Finalizar.
  1. Entrá a https://cran.r-project.org.
  2. Hacé clic en Download R for macOS.
  3. Elegí el instalador que corresponde a tu computadora:
    • Mac con chip Apple (M1, M2, M3, M4…): el que dice arm64.
    • Mac con procesador Intel: el que dice x86_64.
    • ¿No sabés cuál tenés? Menú → Acerca de esta Mac → mirá si dice “Chip Apple” o “Procesador Intel”.
  4. Abrí el archivo .pkg descargado y seguí los pasos con las opciones que vienen por defecto.

Seguí las instrucciones de tu distribución en https://cran.r-project.org/bin/linux/. Si usás Ubuntu, hay instrucciones paso a paso en https://cran.r-project.org/bin/linux/ubuntu/.

Paso 2: instalar RStudio

  1. Entrá a https://posit.co/download/rstudio-desktop/.
  2. Como ya instalaste R, salteá el paso 1 de esa página y hacé clic en el botón azul Download RStudio Desktop (la página detecta tu sistema operativo).
  3. Instalalo:
    • Windows: abrí el .exe descargado y Siguiente hasta el final.
    • macOS: abrí el .dmg y arrastrá el ícono de RStudio a la carpeta Aplicaciones.
  4. Abrí RStudio (no “R”). Tiene que verse más o menos así: una ventana dividida en paneles, con la Consola abajo a la izquierda.
NotaR y RStudio: ¿cuál abro?

Siempre RStudio. R trabaja “por detrás”: RStudio lo usa solo. Es como el motor (R) y el tablero del auto (RStudio).

Paso 3: instalar los paquetes

  1. En RStudio, hacé clic en la Consola (el panel de abajo a la izquierda, donde aparece el símbolo >).
  2. Copiá esta línea completa, pegala en la Consola y apretá Enter:
install.packages(c("tidyverse", "here"))
  1. Van a aparecer muchas líneas de texto en rojo: es normal, no son errores. tidyverse es un “paquete de paquetes” (trae todo lo necesario para leer, ordenar y graficar datos), así que puede tardar varios minutos. Esperá a que vuelva a aparecer el >.
Tip¿Te pregunta algo mientras instala?
  • “Would you like to use a personal library instead?” → escribí yes y Enter.
  • “Do you want to install from sources the packages which need compilation?” → escribí no y Enter.
  • Si te pide elegir un “CRAN mirror” (un servidor), elegí cualquiera; por ejemplo, el primero de la lista (0-Cloud).

Paso 4: comprobar que todo funciona

  1. Descargá el script de prueba:

⬇ Descargar prueba-instalacion.R

  1. En RStudio: File → Open File… y abrí prueba-instalacion.R.
  2. Arriba a la derecha del script, hacé clic en el botón Source.
  3. Mirá la Consola. Si todo está bien, vas a ver algo así:
✔ R 4.x.x instalado.
✔ Estás usando RStudio.
✔ Los 8 paquetes del taller están instalados.
✔ R puede leer datos, transformarlos y guardar una figura.

🎉 ¡Todo listo para el taller!

Si aparece alguna ✘, el mismo mensaje te dice qué hacer. Si no te sale, escribime.

Paso 5: GitHub Desktop y cuenta de GitHub

Esto lo usamos recién en el encuentro 5, pero conviene dejarlo listo.

5a. Crear una cuenta de GitHub

  1. Entrá a https://github.com/signup.
  2. Poné tu correo, una contraseña y un nombre de usuario.
    • Elegí un nombre que te sirva en lo profesional: por ejemplo nombreapellido. Lo van a ver otras personas.
  3. Confirmá tu correo con el código que te llega.
  4. Si te ofrece planes pagos, elegí el gratuito (Free). Alcanza y sobra.

5b. Instalar GitHub Desktop

GitHub Desktop es un programa con botones para usar Git, sin escribir comandos. Ya trae Git incluido: no hace falta instalar nada más.

  1. Entrá a https://desktop.github.com/.
  2. Hacé clic en Download (detecta Windows o macOS).
  3. Instalalo:
    • Windows: abrí el .exe. Se instala solo, sin preguntar nada.
    • macOS: descomprimí el .zip y arrastrá GitHub Desktop a Aplicaciones.
  4. Abrilo y hacé clic en Sign in to GitHub.com. Se abre el navegador: iniciá sesión y autorizá la aplicación.
  5. Cuando te pregunte por Configure Git, dejá tu nombre y tu correo (los de tu cuenta) y hacé clic en Finish.
Nota¿Usás Linux?

GitHub Desktop no tiene versión oficial para Linux. Instalá Git (sudo apt install git en Ubuntu) y en el encuentro 5 usamos la pestaña Git de RStudio.

Problemas frecuentes

Tip“No such file or directory” o problemas con carpetas

Evitá guardar los proyectos del taller en carpetas sincronizadas (OneDrive, Google Drive, Dropbox) o con espacios y tildes en el nombre. Una buena opción es crear una carpeta taller-r directamente en Documentos.

TipEl paquete no se instala (“installation of package had non-zero exit status”)
  1. Cerrá RStudio y volvé a abrirlo.
  2. Volvé a correr el install.packages(...) solo con el paquete que falló.
  3. Si sigue fallando, copiá el mensaje de error completo y mandámelo.
TipMi versión de R es vieja

Instalá la nueva encima (paso 1): no hace falta desinstalar la anterior. Después, en RStudio: Tools → Global Options → General → R version y elegí la nueva. Vas a tener que volver a instalar los paquetes (paso 3).

TipNo tengo computadora para traer

Avisame cuando confirmes tu inscripción y vemos cómo resolverlo (por ejemplo, trabajar en pareja).
